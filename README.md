# TeleQwen AI — Telegram Manager с Qwen Agent

AI-менеджер для Telegram: анализирует переписки, автоматически отвечает через Qwen AI, извлекает события в календарь.

## 🚀 Возможности

- **Автоответчик** — AI отвечает на сообщения когда вы заняты
- **Фильтры** — выбираете кому AI может отвечать
- **Календарь** — AI автоматически извлекает встречи и дедлайны из переписок
- **Аналитика** — статистика работы AI в реальном времени
- **AI-ассистент** — анализ тона, саммари, перевод переписок

## 📋 Требования

- Python 3.10+
- Node.js 18+
- Qwen Code CLI (для AI)
- Telegram аккаунт

## 🔧 Установка и запуск

### 1. Установка Qwen Code CLI

```bash
# Установить Qwen Code глобально
npm install -g @qwen-code/qwen-code

# Проверить установку
qwen --version
```

### 2. Авторизация в Qwen

```bash
# Запустить авторизацию
qwen /auth

# В терминале появится меню:
# ? Select a provider
#   ○ OpenAI
#   ○ Anthropic
#   ● Qwen Account with Subscription  ← ВЫБЕРИТЕ ЭТО
#   ○ Gemini
#   ○ Vertex AI

# После выбора откроется браузер для входа в Qwen Account
# Войдите или создайте аккаунт на https://qwen.ai
```

**Важно:** Нужна подписка Qwen (есть бесплатный trial). После авторизации SDK будет использовать ваши credentials автоматически.

### 3. Получение Telegram API credentials

1. Перейдите на https://my.telegram.org
2. Войдите с номером телефона
3. Перейдите в **API development tools**
4. Создайте приложение:
   - **App title:** TeleQwen (или любое)
   - **Short name:** teleqwen
   - **URL:** можно оставить пустым
   - **Platform:** Desktop
5. Скопируйте **api_id** и **api_hash**

### 4. Настройка backend

```bash
# Перейти в папку проекта
cd teleqwen-ai

# Создать .env файл из шаблона
cp backend/.env.example backend/.env

# Открыть .env и заполнить:
nano backend/.env  # или любой редактор
```

**Содержимое `.env`:**
```env
TG_API_ID=12345678          # ваш api_id из my.telegram.org
TG_API_HASH=abcdef0123456789abcdef0123456789  # ваш api_hash
TG_SESSION=teleqwen         # имя сессии (можно не менять)
```

### 5. Установка зависимостей

```bash
# Backend (Python)
pip install -r backend/requirements.txt

# Frontend (Node.js)
npm install
```

### 6. Запуск

**Терминал 1 — Backend:**
```bash
python backend/main.py
```

При первом запуске Telethon запросит:
1. **Номер телефона** (в формате +79991234567)
2. **Код из Telegram** (придёт в приложение)
3. **Пароль** (если включена 2FA)

После успешной авторизации сессия сохранится в `teleqwen.session`.

**Терминал 2 — Frontend:**
```bash
npm run dev
```

Откройте http://localhost:5173

## 🎯 Использование

### Включение автоответчика

1. Откройте веб-панель
2. Перейдите в **Настройки**
3. Нажмите **Включить** в разделе "Режим Busy"

### Настройка фильтров

1. Перейдите в **Фильтры**
2. Включите/выключите автоответ для конкретных чатов
3. По умолчанию все чаты включены

### Календарь событий

- AI автоматически извлекает события из переписок
- Перейдите в **Календарь** чтобы просмотреть
- Можно добавлять события вручную кнопкой **Добавить**

### AI-ассистент

1. Откройте любой чат
2. Нажмите иконку **Bot** в шапке
3. Используйте быстрые действия:
   - **Анализ тона** — определить настроение переписки
   - **Саммари** — краткое содержание
   - **Предложить ответ** — AI предложит ответ
   - **Перевести** — перевод сообщений

|----------|--------|----------|

## 🔒 Безопасность

- **Секреты** (TG_API_ID, TG_API_HASH) хранятся ТОЛЬКО в `backend/.env`
- **Фронтенд** не содержит никаких ключей
- **Qwen** работает в sandbox-папке без доступа к файлам
- **permission_mode: "plan"** — Qwen не выполняет инструменты
- **Кулдаун 60 сек** — защита от спама ответов

## 🛠️ Режим Busy — как работает

1. Включаете режим в настройках
2. Бот слушает входящие сообщения
3. Проверяет фильтр (разрешён ли автоответ для этого чата)
4. Извлекает календарные события из переписки
5. Берёт контекст последних 10 сообщений
6. Отправляет в Qwen: "ответь или SKIP"
7. Если Qwen ответил SKIP — пропускает
8. Если Qwen дал ответ — отправляет в чат
9. Кулдаун 60 секунд на каждого собеседника

## 🐛 Troubleshooting

**Ошибка: "TG_API_ID / TG_API_HASH not set"**
- Проверьте что создали `backend/.env` и заполнили credentials

**Ошибка: "Failed to connect Telegram"**
- Проверьте правильность api_id и api_hash
- Убедитесь что номер телефона активен

**Ошибка: "Qwen query failed"**
- Проверьте что выполнили `qwen /auth`
- Убедитесь что у вас активна подписка Qwen

**Frontend не подключается к backend**
- Убедитесь что backend запущен на `http://127.0.0.1:8000`
- Проверьте CORS настройки в `backend/main.py`
